```shell
#Stage Ⅰ
export PYTHONPATH=$(pwd)
start_timestep=0 # start frame index for training
end_timestep=-1 # end frame index, -1 for the last frame

python tools/train.py \
    --config_file configs/omnire.yaml \
    --output_root $output_root \
    --project $project \
    --run_name $expname \
    dataset=waymo/3cams \
    data.scene_idx=$scene_idx \
    data.start_timestep=$start_timestep \
    data.end_timestep=$end_timestep
```

## Perception

We use [Dynamo-Depth](https://github.com/YihongSun/Dynamo-Depth.git) to evaluate whether the data synthesized by E2Recon can provide useful supervision for downstream monocular depth estimation.

### Validation Steps

1. Reconstruct driving scenes with E2Recon.

   First train E2Recon on the selected driving scenes and obtain the reconstructed Gaussian scenes.

2. Generate rendered and asset-augmented data.

   Use the trained checkpoint to render RGB images from reconstructed scenes. Then insert controllable assets, such as pedestrians or vehicles, and render synthetic driving data with richer object layouts.

3. Prepare Dynamo-Depth training data.

   Convert the rendered outputs into the data format used by Dynamo-Depth. 

4. Train Dynamo-Depth with different data settings.

   We compare the following settings:
   - real training data only
   - rendered data only
   - rendered data + asset-inserted synthetic data

5. Evaluate on held-out real driving frames.

   The trained depth model is evaluated on held-out validation scenes using standard monocular depth metrics, including Abs Rel, Sq Rel, RMSE, RMSE log, and threshold accuracies.

The validation results show that asset-inserted synthetic data generated by E2Recon can provide complementary supervision signals for monocular depth estimation.
